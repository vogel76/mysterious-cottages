The elf companion's assets, all output of the Blender art pipeline in `../../art` (see `art/README.md`): `room/` holds the rendered room plate, one transparent crop per furniture variant and `manifest.json` with each crop's place in the plate; `sprites/<character>/` holds the packed WebP atlases and the manifest the sprite player draws (`elf/` today). Edit the scripts and re-render; do not edit these files by hand. Each manifest's `source` names the render and the pack that made it: `pnpm art:elf && pnpm art:pack` reproduces the elf's atlas and `pnpm art:check` proves it before a commit.
